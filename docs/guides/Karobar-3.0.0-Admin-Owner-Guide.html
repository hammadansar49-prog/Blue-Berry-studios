Apna business aur Owner account

Karobar mein business banana, company profile set karna aur employees ko apne store se jorna.

Owner aur employee Admin mein farq

Google ya email se business shuru karne wala asal account Owner hota hai. Employee ko Admin role dena usay asal Google/email Owner nahi banata. Cloud-linked employees banane ke liye asal Owner login istemal karein.

Pehli dafa login

  1. Karobar kholein aur internet connect rakhein.
  2. Continue with Google dabayein aur business ki Gmail select karein. Desktop par browser khul sakta hai; login ke baad app par wapas aayein.
  3. Email/password use karna ho to New here? Create an account chunein. Valid email aur kam az kam 6 characters ka password dein; behtar hai lamba, unique password ho.
  4. Dobara aate waqt wahi original account aur login tareeqa istemal karein. Kisi doosri Gmail se naya, alag store khul sakta hai.
Pehle se business maujood hai? Naya account na banayein. Usi purane Owner account se login karein. Firebase Console mein jana aam users ke liye zaroori nahi.

Company profile

My Company mein company name, phone, email, address aur doosri details bharein. Logo/signature chunein aur Save Changes dabayein. Cloud saved ka intezar karein; phir page dobara khol kar details aur sidebar logo check karein.

Employee ka account banayein

Yeh steps asal Owner ke Google/email session mein karein.

Sync, Share & Backup > User Activity > Add User

  1. User Name dein, misaal: ali_cashier01. Har shakhs ka alag naam rakhein; simple letters, numbers aur underscore behtar hain.
  2. Role select karein: Cashier, Manager, Viewer ya Admin. Neeche diya gaya version note zaroor parhein.
  3. Manager ke liye Manager PIN bilkul 4 digits ka dein. PIN sirf mutaliqa zimmedar shakhs ko dein.
  4. Password kam az kam 6 characters ka rakhein. Random Pass se password generate aur Show Password se check kar sakte hain.
  5. ADD dabayein. Error aaye to usay resolve karein; sirf form band hone ko successful cloud account na samjhein.
  6. All Users mein employee check karein aur Cloud saved ka intezar karein.
  7. Employee ko us ka User ID aur password private taur par dein. Owner Gmail/password share na karein.
  8. Doosre device par Employee? Login with User ID se test karein. Store ka naam, data aur zaroori actions verify karein.

Role selection: v3.0.0 ki zaroori limitation

Code inspection mein role-name mismatch mila hai: Add User ke Cashier/Manager/Viewer/Admin roles permissions ke lowercase checks se match nahi karte. Is liye naya employee viewer-jaisa access le sakta hai, aur create/edit buttons band reh sakte hain. Role select karne ko working permissions ki guarantee na samjhein. Production staff rollout se pehle permissions fix aur test karwana zaroori hai.

Yeh guide is limitation ko document karti hai; documentation banate waqt app ka behavior change nahi kiya gaya.

Users, branches aur account safety

Users ki list aur credentials

User Activity > All Users mein users dekhein. Employee ki row khol kar username, role aur masked password dekha ja sakta hai; Show password zahir karta hai. Yeh screen ya screenshot public share na karein.

User remove karne ke liye us user ka Delete action chunein aur confirmation dhyan se parhein. Cloud save hone ke baad removed account ka access dobara test karein. Isay foran har device ki Firebase login session revoke hone ki guarantee na samjhein.

Branch banana

  1. User Activity > Add Branch kholein.
  2. Branch name, phone, address aur kam az kam 6-character password dein; name aur phone required hain.
  3. Save/create complete hone par generated 6-digit branch code aur password private taur par record karein. All Branches mein entry check karein.
  4. Branch device par Branch? Add your branch code se code/password daal kar login aur data verify karein.
Branch creation/login ka live end-to-end test is guide ke liye nahi kiya gaya. Error aaye to branch ko ready na samjhein. Branch session ka Add User independent cloud staff login nahi banata; doosre devices par chalne wale employees asal Owner se create karwayein.

Activity aur password

User Activity > Activity Log se available activity dekhein; user/date filters istemal karein. App ka local Admin password dialog Google account ka password change nahi karta. Email login ke liye Forgot password?, aur Google login ke liye Google account recovery istemal karein.

Shared laptop par kaam ke baad Logout karein. Staff ko sirf us ke apne credentials dein. Backup files mein sensitive business/account information ho sakti hai; unhein private rakhein.

Cloud, backup aur final checklist

Save status ko samjhein

StatusKya karna hai
Cloud savedCloud ne save acknowledge kar diya. Doosre device par same account se verify karein.
Saved on device - waiting for cloudLocal changes pending hain. Internet on rakhein aur cloud save ka intezar karein.
Saved on device - cloud save failedChanges device par hain; cloud save successful nahi. Internet/account check karein aur support ko error dein.
Pending ya failed sync par app data/cache clear, reset ya uninstall na karein. Cloud sync backup ka badal nahi; regular backup bhi rakhein.

Backup file

  1. Sync, Share & Backup > Restore Backup kholein. Page title Backup & Restore hoga.
  2. Create Backup File dabayein aur .json file secure jagah rakhein. Date ke saath alag copies rakhna behtar hai.
  3. Restore sirf zaroorat par karein: pehle current data ka backup lein, phir Choose Backup File se sahi file select karein.
  4. Confirmation mein business name aur records check karein. Restore current business data ko replace karta hai; ghalat file confirm na karein.

Team ko dene se pehle

  • Owner account aur recovery email aap ke control mein hain.
  • Company details/logo save aur reload ke baad check hain.
  • Employee ka login doosre device par test hai.
  • Permissions ki known limitation resolve aur required actions test hain.
  • Latest backup private jagah par hai.

Data nazar na aaye?

Pehle account aur business name check karein. Naya store banane ya purana backup restore karne ki jaldi na karein. Error text, waqt aur app version support ko dein; password ya private backup public na bhejein.
