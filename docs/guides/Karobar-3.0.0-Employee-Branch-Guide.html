Apne store mein login

Yeh guide Owner ke banaye hue employee aur branch accounts ke liye hai.

Employee login

  1. Owner se apna User ID aur password lein. Misaal User ID: ali_cashier01. Yeh sirf misaal hai, ready account nahi.
  2. Karobar kholein, internet connect karein aur Employee? Login with User ID chunein.
  3. User ID aur password daal kar Login dabayein. Password ki capital/small letters aur extra spaces check karein.
  4. Login ke baad business name aur available store data check karein. Ghalat store ho to transactions enter na karein; Owner ko batayein.
Employee banne ke liye Continue with Google ya Create an account use na karein. Owner ke store mein aane ke liye us ka diya hua employee login istemal karein; naya Owner account alag store bana sakta hai.

Branch login

  1. Owner se apni branch ka 6-digit branch code aur password lein.
  2. Login screen par Branch? Add your branch code chunein.
  3. Code/password enter karein aur login ke baad store/branch details check karein.

Branch account aur employee User ID alag login tareeqe hain. Branch ke liye employee screen par code na daalein. Branch workflow ko Owner se pehle verify karwayein.

Dobara app kholne par

Login maange to wahi employee ID ya branch code use karein. Apna password bhool jayein to Owner se rabta karein; naya Google account bana kar purana business data nahi milega.

Roz ka kaam aur permissions

Shift shuru karte waqt

  • Business name aur apni login identity check karein.
  • Internet/sync status dekhein.
  • Sirf apne account par kaam karein; kisi aur ki identity use na karein.
  • Chhoti window par menu button se sidebar kholein aur apna section select karein.

Menu aur kaam

Owner ki di hui access ke mutabiq dashboard, items, parties aur sale invoices jaise sections available ho sakte hain. Invoice save karne se pehle customer, item, quantity, rate aur total check karein. Kisi action par access error aaye to usay bypass karne ki koshish na karein.

v3.0.0 permission limitation: Naye employee roles mein mismatch ki wajah se selected Cashier, Manager ya Admin role ke bawajood create/edit controls unavailable ho sakte hain. Yeh aap ki login ghalti zaroori nahi. Owner ko exact error batayein; permissions fix/test hone tak required staff workflows ready assume na karein.

Manager PIN

Kisi action ke liye Manager PIN maanga jaye to authorized manager se rabta karein. PIN 4 digits hota hai; employee password se alag hai. Doosre employee ka PIN ya Owner password mang kar permissions cross na karein.

Branch ke employees

Branch session mein Add User se bana hua local record independent Firebase employee account nahi hota. Alag laptop/device par employee login chahiye to asal Owner se cloud-linked user create karwayein.

Shift khatam karte waqt

Pending edits save karein, cloud status check karein, aur shared laptop par Logout karein. Save error ho to Owner ko inform karein; sirf window band karna cloud save ki tasdeeq nahi.
